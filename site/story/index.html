A side quest

Avinash missed a notepad calculator, so he built one. This is why, and how.

Said oh-MAH-kus.

Why it exists

Ajith and Avinash were talking through numbers. Avinash used to use Numi, a notepad calculator, on a Mac. After he moved to Linux, on Omarchy, he missed it.

Avinash wrote down what he missed, in a single prompt. About 30 minutes later he had a first version that worked. Then he kept refining it, because he was using it.

Ajith is on a Mac, and he wanted to use Omacus too. So it runs on Linux on Omarchy, on macOS, on Windows, and on the web. They both use it every day.

Avinash built it for himself. He open-sourced it, under the MIT license, in case someone else wanted it too.

How it was built

Avinash didn't hand-write the code. He set the direction, made the decisions, and reviewed what came back. AI agents wrote every line.

It started with Claude. It now runs on Grok Bot. Grok Bot plans the work and runs cloud coding agents. Those agents open pull requests. Grok Bot watches the checks and ships the releases.

What makes that safe enough:

  • Protected main. A change only lands through a pull request.
  • Checks on every system they ship. Linux, macOS, Windows, and the browser build all have to pass.
  • A release is a pull request. When the checks pass, it merges on its own, and the new version goes out.
  • One design guide. docs/DESIGN.md is what keeps the app and the site looking like the same product.
  • Notes for people using it. Release notes say what changed for you, in plain words.

Avinash's part is taste, decisions, and review.

What Avinash learned

Personal notes. Not a method, and not advice.

  1. The short part was the start

    Getting from wishing this existed to a version he could type into was fast. Almost everything he kept came after that.

  2. The safety net matters more than the prompt

    A prompt gets a draft. Avinash trusts the result because main is protected, the checks cover every system they ship, and the notes are written for someone using Omacus.

  3. Taste is the job

    Agents can fill a screen. Choosing what should be quiet, what a sentence should say, and what to leave out is still on Avinash.

  4. One person kept it smaller

    If Avinash wouldn't use a feature on a page of his own, it stayed out.

Contribute

The code is MIT licensed. If something is wrong, or missing, open an issue. If you want to change it, send a pull request.

You can use AI agents too. Avinash does. The same bar applies: the checks have to pass, the design guide is the look, and the notes should make sense to someone using Omacus.
