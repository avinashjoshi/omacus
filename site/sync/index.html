Sync

Pages can open on your other phones and computers. They are encrypted on your device before they leave, and the server cannot read them. There is no sign-up on this page.

Nobody else can read them

Turn on sync in the web app. It is in the sidebar, and on a wide window it is also in the top bar. A short explanation comes first. Then you start fresh, or you join pages that are already on another phone.

Each page is encrypted on that phone or computer before it is sent. The server stores the sealed copy. Omacus cannot read the pages. The company that hosts the server cannot read them either. A share link is a different thing: that page travels inside the link, and only the people you give it to can open it.

The desktop app keeps pages in a folder on this computer. Turn on sync there uses the same explanation, then continues in the web app. Those desktop pages are not uploaded.

What the server can see

The server can see that a sealed copy exists, how large it is, when it was saved, and how many phones and computers are linked. It can see the sealed bytes.

It cannot see the page text, the page names, the recovery words, or the keys. It cannot open a page. There is no email and no password for an Omacus account.

Twelve recovery words

Twelve words open the pages on a new phone or computer. Write them down and keep them somewhere safe. Anyone with the words can open the pages. Omacus does not keep a copy, so lost words cannot be reset.

1 amber2 birch3 cedar4 drift 5 ember6 fern7 grove8 harbor 9 iris10 juniper11 kettle12 lantern

Example words, so you can see the shape. Yours will be different. This page never asks for them.

Link a phone or computer

On a phone that already has the pages, you show a code. On the new phone you type that code. Both sides show the same six numbers, and you confirm they match before the new phone can open the pages. After that, it stays linked. You do not type the recovery words on every launch.

Offline, then caught up

A linked phone keeps working with no connection. Edits wait on that phone and sync when it is back online. A line typed on two phones at the same time is kept on both.

A sealed copy each night

Each night the server saves another sealed copy, and keeps those copies for about 30 days. The nightly copy is the same sealed bytes. It is not opened. If a copy has to be put back, what returns is still sealed, and only your phones can read it.
