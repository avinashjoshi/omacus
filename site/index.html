    Write it like you'd say it.

    No formula syntax to learn. Omacus reads the way you already write notes, and quietly ignores the words that aren't math.

    Units

    Distance, time, temperature, data, cooking, area and hundreds more, converted with in or to.

    3.5 km in miles2.17 miles
    2 cups in ml473.18 ml

    Currencies

    160+ currencies with live exchange rates, cached so it keeps working offline. Symbols or codes, your call.

    $30 in EUR26.75 EUR
    ₹5,000 in USD$52.58

    Time zones

    Abbreviations, cities and countries, with daylight saving handled. Tells you when it lands on another day.

    3pm PST in IST3:30 AM IST (next day)
    noon UTC in Tokyo9:00 PM JST

    Percentages

    The everyday phrasings: of, on, off, as a percent of, and what a number is a percentage of.

    15% off $1,299$1,104.15
    $120 as % of $48025%

    Variables & totals

    Name things once, reuse them below. total, average and prev work over each block.

    rate = $85/hour$85 / hour
    rate * 30 hours$2,550

    Notes, not code

    Headers, comments, labels and plain prose sit right next to the math. Lines read like a notebook.

    Lunch with Sam $18$18
    Rent: $1,450$1,450
    // sheets

    Nothing to save. Ever.

    Keep a sheet per trip, budget or invoice. Like Sublime Text, every keystroke is saved, and closing the window loses nothing.

    • Reopens exactly where you left off, cursor included.
    • Plain text files on disk, so you can search, sync or back them up.
    • Deleted sheets go to the trash, not into the void.
    • Autocomplete for your variables, units and time zones.
    // themes

    Looks like the rest of your desktop.

    On Omarchy, Omacus wears your theme and switches the moment you do. Elsewhere it follows your system's light or dark mode, or any colors you give it.

    Hands stay on the keys.

    Everything has a shortcut, and F1 opens a built-in guide where every example is calculated live.

    New sheet Ctrl N
    Next sheet Ctrl Tab
    Jump to sheet Ctrl 1–9
    Copy last result Ctrl Shift C
    Accept suggestion Tab
    Hide sidebar Ctrl B
    // command line

    Also lives in your terminal.

    The same engine answers one-off questions, or evaluates a whole sheet from a pipe. Handy in scripts, launchers and status bars.

    CLI docs 

    $ omacus '$100 in INR'

$ omacus '3pm PST in IST'

$ printf 'rent = $1450\nrent * 12\n' | omacus -

    Get Omacus.

    Free and MIT licensed. Pick your platform; the latest release is always one command away.

    Omarchy & Arch

    Installs the app, then offers a keybind (Super Ctrl Alt = by default, checked against yours) and a floating window.

    $curl -fsSL omacus.com/install | bash

    Colors follow your Omarchy theme automatically.

    macOS Apple Silicon & Intel

    The one-liner installs Omacus.app into Applications and opens without a security prompt.

    $curl -fsSL omacus.com/install | bash
    Download .dmg

    From the .dmg, macOS asks once: open the app, then System Settings → Privacy & Security → Open Anyway.

    Windows 64-bit

    A single portable omacus.exe. Unzip it anywhere and run it; pin it to Start if you like.

    Download .zip

    If SmartScreen warns about an unknown publisher, choose More info → Run anyway.

    Other Linux x86_64

    The same one-liner works on any distribution, or use a package:

    .deb .rpm .tar.gz

    Ubuntu: sudo apt install ./omacus-linux-x86_64.deb · Fedora: sudo dnf install ./omacus-linux-x86_64.rpm
