    // questions

    Good questions.

    What is Omacus?

    Omacus is a free, open-source notepad calculator for Linux, macOS and Windows. You write calculations in plain words, one per line, and each answer appears beside its line as you type. It understands units, currencies, time zones, percentages, variables and running totals, and it was made first for Omarchy.

    Is Omacus free?

    Yes. Omacus is free and open source under the MIT license. The app has no account, no ads and no tracking. This website only counts visits, with Cloudflare's cookieless analytics.

    Which systems does it run on?

    Omarchy and any 64-bit x86 Linux (as a .deb, .rpm, tarball or one-line installer), macOS on Apple Silicon and Intel, and 64-bit Windows.

    How do I convert time zones?

    Type the time and both zones, like 6pm PST in Tokyo. Omacus answers 10:00 AM JST (next day). It knows abbreviations, cities and countries, and adjusts for daylight saving.

    Does it work offline?

    Yes. Everything is calculated on your computer. The internet is only used to refresh exchange rates and to check for a new version (on launch and every few hours), and the last rates are cached so currency math keeps working offline.

    How is it different from a regular calculator?

    A regular calculator shows one number at a time. Omacus keeps a whole page: every line keeps its answer, you can add notes beside the math, name values and reuse them, and changing a line updates everything below it. Sheets are saved as you type.

    Can I use it from the terminal?

    Yes. omacus '$100 in EUR' prints the answer, and omacus - evaluates a whole sheet from standard input, one result per line.

    Where are my sheets stored?

    As plain text files on your own disk, so you can search, sync or back them up like any other notes. Nothing is uploaded.

    Get Omacus.

    Free and MIT licensed. Pick your platform; the latest release is always one command away.

    Omarchy & Arch

    Installs the app, then offers a keybind (Super Ctrl Alt = by default, checked against yours) and a floating window.

    $curl -fsSL https://omacus.com/install | bash

    Colors follow your Omarchy theme automatically.

    macOS Apple Silicon & Intel

    The one-liner installs Omacus.app into Applications and opens without a security prompt.

    $curl -fsSL https://omacus.com/install | bash
    Download .dmg

    From the .dmg, macOS asks once: open the app, then System Settings → Privacy & Security → Open Anyway.

    Windows 64-bit

    A single portable omacus.exe. Unzip it anywhere and run it; pin it to Start if you like.

    Download .zip

    If SmartScreen warns about an unknown publisher, choose More info → Run anyway.

    Other Linux x86_64

    The same one-liner works on any distribution, or use a package:

    .deb .rpm .tar.gz

    Ubuntu: sudo apt install ./omacus-linux-x86_64.deb · Fedora: sudo dnf install ./omacus-linux-x86_64.rpm
