  16. v0.1.15 Oct 17, 2026

    Calculate off the window's thread, reuse unchanged lines, same limit for every line #12

    • The engine saves the state after each line (fend's variables, the total's block, prev, names). Engine::eval_sheet resumes from the first line that changed, so typing at the end of a long sheet redoes one line; answers from the clock (today, time in Tokyo) are refreshed every time.
    • The desktop app calculates on a worker thread (src/calc.rs) that keeps each sheet's saved calculation and drops older text when newer arrives: the window never waits on math. Copying the sheet on screen reuses its answers when they match its text exactly.

    • The sheet-wide budget is gone: every line gets the same 150 ms, so a line's answer no longer depends on where it sits (from the second review).
    • Tests: reused answers equal a full recalculation at every keystroke of every sheet in cases.txt and through random edits; identical lines get identical answers; the worker never blocks its caller and ends on the newest text.

  18. v0.1.13 Oct 17, 2026

    Fixes from an independent review: no freezes, no confident wrong answers #9

    • Each line gets a time limit (150 ms; 20 ms once a sheet has taken a second), so 100000! or 10^10^7 can't freeze the window, the web app or a shared link that opens with one. Without a clock, a cap on fend's work instead.
    • A line with no answer can say why, quietly in the answer's place: "Can't divide by zero", "Units don't match", "Too big to work out".
    • The prose fallback no longer skips past operators or variables, so rent + 5 is never answered "5". A plain number added to an amount takes its currency: rent + 5 is $1,005, and "prev + 1" after $10 is $11.
    • Variables named a, I, the, at or my are kept as variables.
    • 2 x 3 x 4 is 24 and Tickets 2 x $14 is $28.
    • Percentages apply in order ($100 - 10% - 10% is $81), and a percentage variable works the same way ($100 + tax, where tax = 8%).
    • A title-case word that spells a currency code ("Lunch for Cad $40") is prose unless it follows a number or "in"/"to".
    • Updates install exactly the version whose checksums the app checked, and install.sh now checks every download against the release's SHA256SUMS.txt.
    • engine/tests/cases.txt: sheets with the answer each line should get, including every case from the review.
