Each sheet below is plain text you could type into Omacus as-is. Lines starting with # are headers, // starts a note, words before a colon are labels, and the answers on the right appear as you type. total adds up the block above it, and prev is the line before.

Each one opens in the web app with Open in the web app, live, so you can change a number and watch everything below update. Any sheet you make can travel the same way: Ctrl Shift L copies a share link.

Questions

What is a notepad calculator?

A calculator you use like a notepad: you write calculations in plain words, one per line, alongside notes, and each line shows its answer. Unlike a regular calculator, nothing disappears, and changing one line updates everything that depends on it.

Can I keep several sheets?

Yes. Omacus has a sidebar of sheets, one per trip, budget or project, each saved automatically as a plain text file.

Can I use these sheets myself?

Yes. Copy any sheet above into Omacus and the answers appear as it's pasted. Exchange rates and time zones will reflect the day you paste it.
