Omacus docs

Omacus is a notepad calculator. You type on the left, in words and numbers; the answer to each line appears on the right as you type. This page covers everything it understands and every way to use it.

Install

Omacus runs on Omarchy and any Linux, macOS (Apple Silicon and Intel) and Windows. Every release has notes and downloads for each.

Omarchy, Arch and any Linux

curl -fsSL https://omacus.com/install | bash

This installs Omacus for your user (no root) into ~/.local/bin, with a launcher entry and icon. On Omarchy it then asks whether to add a keybind and a floating-window rule; see Omarchy & Hyprland.

Prefer a package? .deb for Ubuntu and Debian (sudo apt install ./omacus-linux-x86_64.deb), .rpm for Fedora and openSUSE (sudo dnf install ./omacus-linux-x86_64.rpm), or the .tar.gz with an install.sh inside. Prebuilt Linux binaries are x86_64; on ARM, build from source.

macOS

curl -fsSL https://omacus.com/install | bash

Installs Omacus.app into /Applications (or ~/Applications) and links the command-line tool at ~/.local/bin/omacus. Apps installed this way open without a security prompt.

Or with Homebrew, which also opens without a prompt:

brew install --cask avinashjoshi/tap/omacus

You can also download the .dmg for your Mac's chip and drag Omacus to Applications. Omacus isn't notarized by Apple yet, so the first time macOS blocks it:

  1. Open Omacus once. macOS says it can't verify it; click Done.
  2. Open System Settings → Privacy & Security, scroll down, and click Open Anyway next to Omacus.

Or in Terminal: xattr -dr com.apple.quarantine /Applications/Omacus.app. You only do this once.

Windows

irm https://omacus.com/install.ps1 | iex

Run that in PowerShell, or download the installer and open it. Either way Omacus installs for your user (no admin prompt) into %LOCALAPPDATA%\Programs\Omacus, appears in Start, and opens. In a new terminal, omacus 2+2 works too. Omacus isn't signed yet, so a downloaded installer may get a SmartScreen warning: choose More info → Run anyway (the PowerShell line doesn't get one). To remove it, use Settings → Apps; your sheets are kept.

Prefer no installer? The portable .zip holds a single omacus.exe to run from anywhere. Right-click it to Pin to Start; a shortcut's Properties let you set a global shortcut key.

Updating

The version is at the bottom of the sidebar. When a new one is out, a small dot appears next to it; click it to see what's new and choose Update now, and Omacus installs the new version and offers to restart. You can also check any time from About in the help window (F1). Your sheets, keybind and settings stay as they are. From a terminal, omacus update does the same.

On Windows, Update now swaps in the new omacus.exe where it's installed (or wherever you keep the portable one). If you installed the .deb or .rpm, the button opens the download page instead, so you update the same way you installed. Omacus checks GitHub for the latest version number when it starts (at most once an hour) and every 4 hours while it stays open; to turn that off, put check_for_updates = false in settings.toml (see Where files live).

Your first sheet

Open Omacus and start typing. Each line is calculated on its own, and the result appears at the right edge of that line. Lines that aren't math (headers, comments, prose) simply have no result.

# Weekend
Pizza $24 + $6 tip
Movie tickets 2 * $14
total

Click any result to copy it. Everything is saved as you type, so just close the window when you're done; your sheet is there next time, with the cursor where you left it. Press F1 any time for the built-in guide.

Arithmetic

The usual operators, plus words for them. x between numbers multiplies, k and M are thousands and millions, ^ is a power. A comma followed by three digits groups thousands (1,234); followed by any other number of digits it's a decimal comma, so 1,5 is 1.5 and €12,50 is €12.50. Dots in threes before a decimal comma group thousands too: €1.234,56 is €1,234.56. lakh and crore after a number are 100,000 and 10,000,000.

You typeOmacus shows
2 + 2 * 38
(1 + 2) ^ 327
sqrt(144) + 10 mod 313
5 x 315
10 times 3 plus 232
1.5k * 46,000
1e6 / 3333,333.33

Functions include sqrt, abs, round, floor, ceil, sin, cos, tan, log, ln and exp; constants pi and e.

Percentages

Say percentages the way you would out loud: of, on, off, as a percent of. A tip or a tax on top works with a word in between, and a bill splits 3 ways or between 4 people. Percentages added or taken away apply one after another ($100 - 10% - 10% is $81), a percentage times a number is that share of it (10% * 200 is 20), and a percentage kept in a variable works the same way: tax = 8%, then $100 + tax.

Totals & prev

total (or sum) adds up the lines above it, back to the last blank line or header, so a blank line starts a new block. average (or avg, mean) works the same way. prev is the result of the line just above. Either can go in a calculation too: total * 1.08, total in EUR. Plain numbers in a block of dollars count as dollars.

You typeOmacus shows
Coffee $4.50$4.50
Lunch with Sam $18$18
Taxi $12$12
total$34.50
average$11.50
prev * 2$23

Time zones

Convert a time between zones by abbreviation (PST, EST, CET, JST, IST…), city (London, Tokyo, San Francisco) or country (Japan, Germany). Abbreviations follow daylight saving: PST in July means Pacific time, which is then PDT. When the answer falls on another day, it says so. Add a date to plan ahead, like on Dec 1, tomorrow or next Monday, and daylight saving is applied for that day.

You typeOmacus shows

Standup 9:30am PST in Berlin6:30 PM CEST
3pm PST on Dec 1 in London11:00 PM GMT, Tue 1 Dec
9am PST tomorrow in Tokyo1:00 AM JST, Mon 19 Oct
3pm PST in IST3:30 AM IST (next day)

For the current time somewhere, write time in Tokyo or now in London. A time without a zone means your local time: 3pm in London.

Dates

today, now, tomorrow, yesterday or any date, plus or minus minutes, hours, days, weeks, months or years. Take one date from another for the days between them. A date without a year is this year's. Days, weeks, months and years move along the calendar, so a clock change in between never lands you on the wrong day; minutes and hours are time that passes.

todayFriday, 16 October 2026 tomorrow + 2 weeksSaturday, 31 October 2026 now - 90 minutesFri, 16 Oct 2026, 7:09 AM Jan 31 + 1 monthSaturday, 28 February 2026 Dec 25 - Dec 124 days next FridayFriday, 23 October 2026 last MondayMonday, 12 October 2026

For a time of day, add or take away minutes and hours from a clock time, or count from now. Add in and a place to see it there.

3pm + 45 min3:45 PM 9:30am PST + 2 hours in London7:30 PM BST in 90 minutesthe time 90 minutes from now in 3 hours in Tokyothat time in Tokyo

Count the days to or from a date: until counts to the next one, since from the last one. Ask in days, weeks, months or workdays (Monday to Friday; public holidays aren't known). Christmas, New Year's, Halloween and Valentine's Day work by name. Dates with slashes work when there's only one way to read them (12/25 or 25/12); for one like 2/3, write the month (Feb 3), since it's 3 February in some places and 2 March in others.

Notes & prose

A sheet is a notebook first. Lines starting with # are headers, // starts a comment (on its own line or after the math), and "quoted text" is ignored. A label before a colon is left out of the math, and words Omacus doesn't know are skipped.

You typeOmacus shows
# A header—
// a comment line—
Rent: $1,450$1,450
Lunch with Sam $18$18
"quoted text" 40 + 242
Tip: if a word you meant as prose happens to be a unit (like at or a), put it in a label (Hotel at the beach: $120) or in quotes.

Sheets

The sidebar lists your sheets; a sheet's title is its first line. Create as many as you like, one per trip, budget, invoice or project.

  • Always saved. Every change is written within half a second, and again when you close. There is no save command and nothing to lose.
  • Picks up where you left off. Order, the open sheet, each sheet's cursor and whether the sidebar is shown all come back next time.
  • Deleting is safe. Deleted sheets move to a trash folder next to your sheets; copy one back to restore it.
  • Plain text. Each sheet is a .txt file, so you can search, sync or back them up with anything.

The ⋯ above a sheet, the ⋯ on its row in the sidebar, and a right-click on that row all open the same menu: New sheet, Move up, Move down, Copy with answers, Copy as Markdown table, Share link and Delete sheet.

Sharing & the web app

Any sheet can travel as a link. Share above the sheet, or Ctrl Shift L, copies one like omacus.com/app#v1.U1bwyS…. Whoever opens it sees the sheet in Omacus in the browser, with every answer worked out live by the same engine as the desktop app.

  • The sheet is the link. It's compressed into the part after #, which browsers never send to a server, so Omacus never sees or stores it. Anyone who has the link can read the sheet, so share it the way you'd share a document.
  • Answers are recalculated when it's opened. Currencies use that day's rates, and today or days until count from the day it's opened.
  • Length. A typical sheet makes a link of a few hundred characters. Past about 2,000, some email and SMS apps can cut a link off; past 8,000, some chat apps can too. Omacus tells you the length when it copies one. For a very long sheet, Ctrl Shift M copies it as a Markdown table instead.

Opening a link in the app

A shared sheet opens as a new sheet (or switches to it, if you already have it):

  • On the web page, choose Open in Omacus. The installer and the macOS app register omacus:// links, and Windows registers them the first time Omacus runs.
  • Paste a link into any sheet: it opens the shared sheet instead of pasting the text.
  • From a terminal: omacus open 'https://omacus.com/app#v1.…'.

The web app

omacus.com/app is Omacus in any modern browser, on a computer or a phone, with nothing to install. Sheets you make there are saved in that browser on that device, and are never uploaded. Export them from the ⋯ menu as a .zip of .txt files, the same format as the desktop app's sheets folder, and import them anywhere.

Chrome, Edge and Android can install it as an app (⋯ → Install as an app), and it works offline once opened. On iPhone and iPad, choose Share → Add to Home Screen: Safari otherwise clears a site's data after seven days without a visit.

Autocomplete

After two letters, Omacus suggests your sheet's variables, then keywords, time zones and units. Tab accepts, ↑ ↓ choose, Esc dismisses. Enter always starts a new line and never accepts a suggestion, so 3 km in followed by Enter can't turn into inch. Short connecting words like in, to and of never trigger suggestions.

Themes

Omacus picks its colors in this order:

  1. Your own theme.toml, if you've made one (see where files live).
  2. On Omarchy, the active Omarchy theme. It switches live when you run omarchy theme set.
  3. Otherwise a built-in light or dark theme that follows your system setting, also live.

A theme.toml uses the same keys as an Omarchy theme's colors.toml. Every key is optional:

mode = "dark"# or "light" background = "#121212"# sheet background dark_background = "#0d0d0d"# sidebar and popups foreground = "#bebebe"# text bright_foreground = "#eaeaea"# numbers light_foreground = "#8a8a8d"# labels and operators dark_foreground = "#555555"# comments accent = "#e68e0d"# results, headers, cursor cyan = "#bebebe"# keywords like in, of, total magenta = "#d35f5f"# variables selection = "#2a2a2a"# selection and the active sheet lighter_background = "#1e1e1e"# hover

Command line

The omacus command uses the same engine as the app.

omacus '$100 in EUR'# one expression → prints the answer omacus '6pm PST in Tokyo' printf 'rent = $1450\nrent * 12\n' | omacus -# a whole sheet from stdin, one result per line omacus - < ~/notes/budget.txt omacus# no arguments: open the window omacus --version# which version you have omacus update# install the latest version omacus open '<share link>'# open a shared sheet in the window

A single expression exits with status 1 when there's no answer, which makes it easy to use in scripts. On Windows, omacus.exe "..." works the same from a terminal.

Omarchy & Hyprland

When the installer runs on Omarchy, it asks:

  1. Add a Hyprland keybind and floating window for Omacus?
  2. Which key? The default is Super Ctrl Alt =. Whatever you choose is checked against your current bindings first. If it's taken, the installer tells you what it does and asks again, so it never overrides one of Omarchy's shortcuts.
  3. Also use the Calculator key? For keyboards that have one; it replaces Omarchy's default calculator on that key.

Your config files are backed up first (*.bak.<timestamp>), nothing is added twice, and the change is rolled back if Hyprland reports an error. For unattended installs, pass the answer:

curl -fsSL https://omacus.com/install | bash -s -- --hyprland# default key curl -fsSL https://omacus.com/install | bash -s -- --key "SUPER ALT + N"# your key curl -fsSL https://omacus.com/install | bash -s -- --no-hyprland# leave Hyprland alone

To set it up by hand, add to ~/.config/hypr/bindings.lua and ~/.config/hypr/looknfeel.lua:

o.bind("SUPER + CTRL + ALT + EQUAL", "Omacus calculator", { launch = "omacus", focus = "^omacus$" })
o.window("^omacus$", { float = true, size = { 980, 600 }, center = true })

The keybind launches Omacus, or focuses it if it's already open. Esc closes it again.

FAQ

How do I update Omacus?

Click the version at the bottom of the sidebar when it shows a dot, use Check for updates in About (F1), or run omacus update. See Updating.

A line shows no result. Why?

Omacus only shows answers it's sure about. Usually the line mixes things that can't be combined (dollars plus kilometres) or uses a word as a unit by accident. Try the expression on its own, and if you think it should work, open an issue with the exact line.

Does it need the internet?

Only to refresh exchange rates and to check for a new version when it starts and every few hours (which you can turn off; see Updating). Everything else is calculated on your computer, and cached rates keep currency math working offline.

macOS says it can't verify the app.

That's because Omacus isn't notarized by Apple yet. Install with the one-line installer to avoid the prompt, or allow it once under System Settings → Privacy & Security → Open Anyway.

Windows SmartScreen warns about an unknown publisher.

Choose More info → Run anyway. The warning appears because the executable isn't code-signed yet.

Who can see a sheet I share?

Anyone you give the link to. The sheet is inside the link itself, after the #, which browsers don't send to servers, so it isn't uploaded or stored anywhere. Don't share a link to a sheet you'd want kept private.

Is my data sent anywhere?

No. Sheets stay on your disk. Omacus makes two kinds of request: one for exchange rates, and a check of the latest version number on GitHub. Neither sends anything about you or your sheets, and the version check can be turned off with check_for_updates = false in settings.toml (see Where files live).

How it works

Omacus is a single Rust program: one native window and one engine, shared by the app and the command line. Every keystroke re-evaluates the sheet from top to bottom. For each line:

ClassifyBlank lines and headers start a new block; comments are skipped; total, average and dates are handled directly.
RewriteThe notepad layer strips labels and quotes, turns €20 into 20 EUR, and rewrites % on, % off and as % of into plain arithmetic.
Evaluatefend does the math, with units and currencies, in a context shared by the whole sheet, so variables carry down. Unknown words are dropped and the line is retried.
FormatResults are rounded for reading, given thousands separators, and painted on the first row of their line.

Each result also lands in a hidden variable, which is how prev, total and named totals see the lines above them. Time zones use the IANA time-zone database, so daylight saving is always right.

The window is drawn with egui. The editor lays the text out first, and Omacus reads back where each line landed so results stay aligned even when long lines wrap.

Contributing

Bug reports and ideas are very welcome: open an issue, and for a wrong answer, paste the exact line you typed and what you expected. Pull requests too.

To build from source you need Rust:

git clone https://github.com/avinashjoshi/omacus && cd omacus cargo run --release# open the window cargo test# the engine, sheets, time zones, help examples ./install.sh# Linux: build and install for your user

Releases are automatic: bumping version in Cargo.toml on main runs the tests on Linux, macOS and Windows, builds every package, and publishes a GitHub release with notes. Omacus is MIT licensed.
