Omacus docs

Omacus is a notepad calculator. You type on the left, in words and numbers; the answer to each line appears on the right as you type. This page covers everything it understands and every way to use it.

Install

Omacus runs on Omarchy and any Linux, macOS (Apple Silicon and Intel) and Windows. Every release has notes and downloads.

Omarchy, Arch and any Linux

curl -fsSL https://omacus.com/install | bash

This installs Omacus for your user (no root) into ~/.local/bin, with a launcher entry and icon. On Omarchy it then asks whether to add a keybind and a floating-window rule; see Omarchy & Hyprland.

Prefer a package? .deb for Ubuntu and Debian (sudo apt install ./omacus-linux-x86_64.deb), .rpm for Fedora and openSUSE (sudo dnf install ./omacus-linux-x86_64.rpm), or the .tar.gz with an install.sh inside. Prebuilt Linux binaries are x86_64; on ARM, build from source.

macOS

curl -fsSL https://omacus.com/install | bash

Installs Omacus.app into /Applications (or ~/Applications) and links the command-line tool at ~/.local/bin/omacus. Apps installed this way open without a security prompt.

Or with Homebrew, which also opens without a prompt:

brew install --cask avinashjoshi/tap/omacus

You can also download the .dmg for your Mac's chip and drag Omacus to Applications. The app isn't notarized yet. On macOS 15 or later, open it once, then System Settings → Privacy & Security → Open Anyway. On an older Mac, right-click the app and choose Open.

Windows

irm https://omacus.com/install.ps1 | iex

Run that in PowerShell, or download the installer and open it. Either way Omacus installs for your user (no admin prompt) into %LOCALAPPDATA%\Programs\Omacus, appears in Start, and opens. In a new terminal, omacus 2+2 works too. Omacus isn't signed yet, so a downloaded installer may get a SmartScreen warning: choose More info → Run anyway (the PowerShell line doesn't get one). To remove it, use Settings → Apps; your pages are kept.

Prefer no installer? The portable .zip holds a single omacus.exe to run from anywhere. Right-click it to Pin to Start; a shortcut's Properties let you set a global shortcut key.

Updating

The version is at the bottom of the sidebar. When a new one is out, a small dot appears next to it; click it to see what's new and choose Update now, and Omacus installs the new version and offers to restart. You can also check any time from About in the help window (F1). Your pages, keybind and settings stay as they are. From a terminal, omacus update does the same. The same notes are on the updates page.

On Windows, Update now swaps in the new omacus.exe where it's installed (or wherever you keep the portable one). If you installed the .deb or .rpm, the button opens the download page instead, so you update the same way you installed. Omacus checks GitHub for the latest version number when it starts (at most once an hour) and every 4 hours while it stays open; to turn that off, put check_for_updates = false in settings.toml (see Where files live).

Your first page

Open Omacus and start typing. Each line is calculated on its own, and the result appears at the right edge of that line. Lines that aren't math (headers, comments, prose) simply have no result.

# Weekend
Pizza $24 + $6 tip
Movie tickets 2 * $14
total

Click any result to copy it. Everything is saved as you type, so just close the window when you're done; your page is there next time, with the cursor where you left it. Press F1 any time for the built-in guide.

Arithmetic

The usual operators, plus words for them. x between numbers multiplies, k and M are thousands and millions, ^ is a power. A comma followed by three digits groups thousands (1,234); followed by any other number of digits it's a decimal comma, so 1,5 is 1.5 and €12,50 is €12.50. Dots in threes before a decimal comma group thousands too: €1.234,56 is €1,234.56. lakh and crore after a number are 100,000 and 10,000,000.

You typeOmacus shows
2 + 2 * 38
(1 + 2) ^ 327
sqrt(144) + 10 mod 313
5 x 315
10 times 3 plus 232
1.5k * 46,000
1e6 / 3333,333.33

Functions include sqrt, abs, round, floor, ceil, sin, cos, tan, log, ln and exp; constants pi and e.

Percentages

Say percentages the way you would out loud: of, on, off, as a percent of. A tip or a tax on top works with a word in between, and a bill splits 3 ways or between 4 people. Percentages added or taken away apply one after another ($100 - 10% - 10% is $81), a percentage times a number is that share of it (10% * 200 is 20), and a percentage kept in a variable works the same way: tax = 8%, then $100 + tax.

Variables

Write name = value to remember something for the rest of the page. Variable names are letters, digits and underscores. The name where you define it is one colour, and a later use of it is another. Keywords and units have a third. Hover a name, or a number such as 1.5k, to see its value. Click an answer to copy it. A value from another page is @handle.variable, for example @trip.total. The handle is the page's short name. See Folders, locks & handles.

You typeOmacus shows
rent = $1,450$1,450
rent * 12$17,400
rate = $85/hour$85 / hour
rate * 30 hours$2,550

Runway, burn, MRR and a round: For founders.

Totals & prev

total (or sum) adds up the lines above it, back to the last blank line or header, so a blank line starts a new block. average (or avg, mean) works the same way. prev is the result of the line just above. Either can go in a calculation too: total * 1.08, total in EUR. Plain numbers in a block of dollars count as dollars.

The same names also take arguments: sum(1, 2, 3) is 6, avg(2, 4) is 3, and min and max pick from the list. A comma inside the parentheses separates arguments (sum($5, $10) is $15). A thousands group stays one number, inside or outside a call: sum(1,000, 2,000) is 3,000, and 1,000 + 1 is 1,001. total, average and mean are the same functions.

Coffee $4.50$4.50
Lunch with Sam $18$18
Taxi $12$12
total$34.50
average$11.50
prev * 2$23

Time zones

Convert a time between zones by abbreviation (PST, EST, CET, JST, IST…), city (London, Tokyo, San Francisco) or country (Japan, Germany). Abbreviations follow daylight saving: PST in July means Pacific time, which is then PDT. When the answer falls on another day, it says so. Add a date to plan ahead, like on Dec 1, tomorrow or next Monday, and daylight saving is applied for that day.

Dates

today, now, tomorrow, yesterday or any date, plus or minus minutes, hours, days, weeks, months or years. Take one date from another for the days between them. A date without a year is this year's. Days, weeks, months and years move along the calendar, so a clock change in between never lands you on the wrong day; minutes and hours are time that passes.

todayFriday, 16 October 2026 tomorrow + 2 weeksSaturday, 31 October 2026 now - 90 minutesFri, 16 Oct 2026, 7:09 AM Jan 31 + 1 monthSaturday, 28 February 2026 Dec 25 - Dec 124 days next FridayFriday, 23 October 2026 last MondayMonday, 12 October 2026

For a time of day, add or take away minutes and hours from a clock time, or count from now. Add in and a place to see it there.

3pm + 45 min3:45 PM 9:30am PST + 2 hours in London7:30 PM BST in 90 minutesthe time 90 minutes from now in 3 hours in Tokyothat time in Tokyo

Count the days to or from a date: until counts to the next one, since from the last one. Ask in days, weeks, months or workdays (Monday to Friday; public holidays aren't known). Christmas, New Year's, Halloween and Valentine's Day work by name. Dates with slashes work when there's only one way to read them (12/25 or 25/12); for one like 2/3, write the month (Feb 3), since it's 3 February in some places and 2 March in others.

Notes & prose

A page is one plain-text document, and any line can be a note, a calculation, or both. Omacus reads the line after a markdown prefix (#, -, *, 1., - [ ], >): if what remains is math, it computes (- hotel = 3 nights * $180 sets hotel to $540), otherwise the line is prose. Variables carry across the whole page, including prose. # at the start of a line is a heading; # later on the line is a comment, like //, and is drawn in the comment colour. Ctrl P previews the page as rendered notes. Each source line stays its own line, a blank line stays blank, and a comment is a quiet note between the expression and its answer. With the answers column on, each answer sits in a column on the right; with it off, the answer follows the line. The same layout is what Print and Export PDF use. Tables are drawn in the preview, and a cell is not calculated. Export PDF names the file after the page and writes it to Downloads (or a folder chosen in Settings). If that file is already there, Omacus asks before replacing it. In the browser, Print and Export PDF use the page title, and the browser decides the folder.

You typeOmacus shows
# A header—
// a comment line—
Rent: $1,450$1,450
Lunch with Sam $18$18
"quoted text" 40 + 242
- hotel = 3 nights * $180$540
hotel * 2$1,080
rent = $100 # monthly$100
Tip: if a word you meant as prose happens to be a unit (like at or a), put it in a label (Hotel at the beach: $120) or in quotes.

Pages

The sidebar lists your pages; a page's title is its first line. Create as many as you like, one per trip, budget, invoice or project.

  • Always saved. Every change is written within half a second, and again when you close. There is no save command and nothing to lose.
  • Picks up where you left off. Order, the open page, each page's cursor, and whether the sidebar is expanded (and how wide) all come back next time. Drag the sidebar's right edge to resize it. Ctrl B collapses it to a thin rail; click the logo there to open it again.
  • Deleting is safe. Deleted pages move to Recently deleted (a trash folder next to your pages). Click one to read it; Restore puts it back, and Delete forever removes it.
  • Plain text. Each page is a .txt file, so you can search it or back it up with anything.

The ⋯ above a page, the ⋯ on its row in the sidebar, and a right-click on that row all open the same menu: Rename, Share link, Copy / Export (Copy with answers, Copy as Markdown table, Preview), Handle…, Move up, Move down, Move to folder…, the lock actions, and Delete page. The sidebar footer shows the logo, the version, Settings, and help.

The first time Omacus opens, and only when you have no pages yet, it adds the welcome page and an Examples folder: Trip Budget, Groceries, Monthly budget, Cooking, and Time zones. Monthly budget reads @groceries.total and @trip.total. Deleting those pages does not bring them back. A library that already has pages is left as it is.

Folders, locks & handles

  • Folders. Pages can sit in folders, two levels deep. Drag a page onto a folder, or choose Move to folder… . A folder's menu adds a page, adds a nested folder, renames the folder, or deletes it. New folder is also in the sidebar.
  • A password lock. Lock… on a page or a folder asks you to choose a password, then locks it. Save that password in a password manager. The file is sealed with Argon2id and XChaCha20-Poly1305. A forgotten password cannot be recovered. Unlock… opens it for this session. Change password… and Remove lock… need the current password, and removing a lock keeps the page. Lock now seals every open page and folder. Settings chooses how soon an unlocked page locks again: 1, 5, 15, 30, or 60 minutes, or Never. Quitting locks them too. The command line and MCP skip a locked page unless you pass its password.
  • Handles. Each page has a short name taken from its title, so Trip Budget is trip. Handle… changes it. Another page reads a value with @handle.variable. @trip.total is the last assignment of total on that page. Typing @ lists pages. F2 renames a variable on this page and in @handle.name on the others.

End-to-end encrypted sync is in the web app. Turn on sync is in the sidebar. Twelve recovery words open the pages again. The server cannot read them. The desktop app does not upload pages yet. Sync explains how it works.

Sharing & the web app

Any page can travel as a link. Share link in the ⋯ menu, or Ctrl Shift L, copies one like app.omacus.com#v1.U1bwyS…. Whoever opens it sees the page in Omacus in the browser, with every answer worked out live by the same engine as the desktop app.

  • The page is the link. It's compressed into the part after #, which browsers never send to a server, so Omacus never sees or stores it. Anyone who has the link can read the page, so share it the way you'd share a document.
  • Answers are recalculated when it's opened. Currencies use that day's rates, and today or days until count from the day it's opened.
  • Length. A typical page makes a link of a few hundred characters. Past about 2,000, some email and SMS apps can cut a link off; past 8,000, some chat apps can too. Omacus tells you the length when it copies one. For a very long page, Ctrl Shift M copies it as a Markdown table instead.

Opening a link in the app

A shared page opens as a new page (or switches to it, if you already have it):

  • On the web page, choose Open in Omacus. The installer and the macOS app register omacus:// links, and Windows registers them the first time Omacus runs.
  • Paste a link into any page: it opens the shared page instead of pasting the text.
  • From a terminal: omacus open 'https://app.omacus.com#v1.…'.

The web app

app.omacus.com is Omacus in any modern browser, on a computer or a phone, with nothing to install. Pages you make there are saved in that browser on that device, and are never uploaded. The same first-run Examples folder, folders, locks, and @handle.variable references are there. Export all pages from Settings as a .zip of .txt files, the same format as the desktop app's pages folder, and import them anywhere.

On a phone the top bar is a solid strip with the page name. Pages opens as a drawer, with Settings and the version at the bottom. The browser keeps a smaller set of shortcuts: Ctrl B, Ctrl J, Alt ↑ / Alt ↓, Ctrl Shift L, Ctrl ,, Ctrl \, Ctrl P, and F2. Move to folder… and Lock… are in the ⋯ menu. New page is the + in the pages list. The web app's themes are Auto, Light, Dark, Paper, and Dusk.

Chrome, Edge and Android can install it as an app (⋯ → Install as an app), and it works offline once opened. Cached exchange rates keep currency math working, and the page says when rates may be stale. On iPhone and iPad, choose Share → Add to Home Screen: Safari otherwise clears a site's data after seven days without a visit.

Autocomplete

After two letters, Omacus suggests your page's variables, then keywords, time zones and units. Each row shows the kind and a short description. Tab accepts, ↑ ↓ choose, Esc dismisses. Enter starts a new line and does not accept a suggestion, so 3 km in followed by Enter can't turn into inch. Ctrl Space opens the suggestions on purpose, and then Enter accepts the chosen one. Short connecting words like in, to and of never trigger suggestions.

Themes

Settings is a tab in the same window as About. Ctrl , or the gear in the sidebar footer (and on the collapsed strip) opens that tab. Typing settings in the page switcher (Ctrl J) opens it too. The footer also shows the version; a dot there means a newer one is out. It chooses the theme, whether answers sit in a column, the PDF export folder, and whether Omacus checks for updates. The same choices are saved in settings.toml (see where files live). Ctrl \ hides the answers column, so each answer sits after its line. The logo in the footer opens the About tab of that window.

Auto picks colors in this order:

  1. Your own theme.toml, if you've made one.
  2. On Omarchy, the active Omarchy theme. It switches live when you run omarchy theme set.
  3. Otherwise a built-in light or dark theme that follows your system setting, also live.

Or pick a built-in theme that ignores those files: Light, Dark, Paper (warm paper) or Dusk (a blue night). Omarchy uses only the Omarchy theme. Custom uses only your theme.toml. The web app has Auto, Light, Dark, Paper and Dusk, and follows the device when set to Auto.

A theme.toml uses the same keys as an Omarchy theme's colors.toml. Every key is optional:

mode = "dark"# or "light" background = "#121212"# page background dark_background = "#0d0d0d"# sidebar and popups foreground = "#bebebe"# text bright_foreground = "#eaeaea"# numbers light_foreground = "#8a8a8d"# labels and operators dark_foreground = "#555555"# comments accent = "#e68e0d"# results, headers, cursor cyan = "#bebebe"# keywords and units magenta = "#d35f5f"# a name where it is used green = "#9ece6a"# a name where it is defined selection = "#2a2a2a"# selection and the active page lighter_background = "#1e1e1e"# hover

Command line

The omacus command uses the same engine, and the same pages, as the app. With no arguments it opens the window. A bare expression still prints one answer.

omacus '3.5 km in miles'# 2.17 miles omacus eval '3.5 km in miles' omacus eval --json '2 + 2'# JSON, one entry per line printf 'a = 5\na * 3\n' | omacus eval# a whole page, one answer per line printf 'a = 5\na * 3\n' | omacus - omacus - < ~/notes/budget.txt omacus pages list omacus pages show 'Trip Budget'# the page, with its answers omacus pages new 'Weekend Plans' omacus pages new Groceries --from-file list.txt omacus pages append Groceries 'milk $3' omacus pages rm 'Weekend Plans'# moved to Recently deleted omacus pages export 'Trip Budget' --md# a Markdown table on stdout omacus pages export 'Trip Budget' --pdf# a PDF in the export folder omacus completions bash# also zsh, fish, powershell omacus# no arguments: open the window omacus --version# which version you have omacus update# install the latest version omacus open '<share link>'# open a shared page in the window

A page can be named by its title, its id, or a unique prefix, so trip is enough for Trip Budget. If more than one page fits, omacus lists them and changes nothing. omacus pages --help lists every page command. A single expression exits with status 1 when there's no answer, which makes it easy to use in scripts. On Windows, omacus.exe "..." works the same from a terminal.

These commands read and write the pages in the data folder. The window re-reads that folder every few seconds, and again when it regains focus, so an edit from the command line shows up in the app. Set OMACUS_DATA_DIR to use a different folder. A locked page is not printed, exported, or changed unless you pass --password.

MCP

omacus mcp runs a Model Context Protocol server on stdin and stdout, so Claude Desktop, Cursor, and other clients can calculate and use your pages. The tools are evaluate, list_pages, read_page, create_page, append_page, update_page, and delete_page (which moves a page to Recently deleted). Each page is also a resource at omacus://page/{id}. A locked page is not returned without its password. The server uses the same files as the app, so the window picks up the edits.

Claude Desktop and Cursor take the same block. omacus has to be on PATH, which the installers arrange. For Claude, save it in claude_desktop_config.json (~/Library/Application Support/Claude/ on macOS, ~/.config/Claude/ on Linux, %APPDATA%\Claude\ on Windows). For Cursor, save it as .cursor/mcp.json in the project or in your home directory. Restart the client afterwards.

{
  "mcpServers": {
    "omacus": {
      "command": "omacus",
      "args": ["mcp"]
    }
  }
}

Omarchy & Hyprland

When the installer runs on Omarchy, it asks:

  1. Add a Hyprland keybind and floating window for Omacus?
  2. Which key? The default is Super Ctrl Alt =. Whatever you choose is checked against your current bindings first. If it's taken, the installer tells you what it does and asks again, so it never overrides one of Omarchy's shortcuts.
  3. Also use the Calculator key? For keyboards that have one; it replaces Omarchy's default calculator on that key.

Your config files are backed up first (*.bak.<timestamp>), nothing is added twice, and the change is rolled back if Hyprland reports an error. For unattended installs, pass the answer:

curl -fsSL https://omacus.com/install | bash -s -- --hyprland# default key curl -fsSL https://omacus.com/install | bash -s -- --key "SUPER ALT + N"# your key curl -fsSL https://omacus.com/install | bash -s -- --no-hyprland# leave Hyprland alone

To set it up by hand, add to ~/.config/hypr/bindings.lua and ~/.config/hypr/looknfeel.lua:

o.bind("SUPER + CTRL + ALT + EQUAL", "Omacus calculator", { launch = "omacus", focus = "^omacus$" })
o.window("^omacus$", { float = true, size = { 980, 600 }, center = true })

The keybind launches Omacus, or focuses it if it's already open. Ctrl Q quits it again.

FAQ

How do I update Omacus?

Click the version at the bottom of the sidebar when it shows a dot, use Check for updates in About (F1), or run omacus update. See Updating.

A line shows no result. Why?

Omacus only shows answers it's sure about. Usually the line mixes things that can't be combined (dollars plus kilometres) or uses a word as a unit by accident. Try the expression on its own, and if you think it should work, open an issue with the exact line.

Does it need the internet?

Only to refresh exchange rates and to check for a new version when it starts and every few hours (which you can turn off; see Updating). Everything else is calculated on your computer, and cached rates keep currency math working offline.

macOS says it can't verify the app.

That's because Omacus isn't notarized by Apple yet. On macOS 15 or later, open it once, then System Settings → Privacy & Security → Open Anyway. On an older Mac, right-click the app and choose Open.

Windows SmartScreen warns about an unknown publisher.

Choose More info → Run anyway. The warning appears because the executable isn't code-signed yet.

Who can see a page I share?

Anyone you give the link to. The page is inside the link itself, after the #, which browsers don't send to servers, so it isn't uploaded or stored anywhere. Don't share a link to a page you'd want kept private.

Is my data sent anywhere?

Desktop pages stay on your disk. The desktop app does not upload them. The web app can send a sealed copy when you turn on sync. The server cannot read the pages. Omacus also fetches exchange rates, and on the desktop it checks the latest version number on GitHub. Neither of those sends anything from your pages, and the version check can be turned off with check_for_updates = false in settings.toml (see Where files live). Sync explains the sealed copy.

How it works

Omacus is a single Rust program: one native window and one engine, shared by the app and the command line. Every keystroke re-evaluates the page from top to bottom. For each line:

ClassifyBlank lines and headers start a new block; comments are skipped; total, average and dates are handled directly.
RewriteThe notepad layer strips labels and quotes, turns €20 into 20 EUR, and rewrites % on, % off and as % of into plain arithmetic.
Evaluatefend does the math, with units and currencies, in a context shared by the whole page, so variables carry down. Unknown words are dropped and the line is retried.
FormatResults are rounded for reading, given thousands separators, and painted on the first row of their line.

Each result also lands in a hidden variable, which is how prev, total and named totals see the lines above them. Time zones use the IANA time-zone database, so daylight saving is always right.

The window is drawn with egui. The editor lays the text out first, and Omacus reads back where each line landed so results stay aligned even when long lines wrap.

Contributing

Bug reports and ideas are very welcome: open an issue, and for a wrong answer, paste the exact line you typed and what you expected. Pull requests too.

To build from source you need Rust:

git clone https://github.com/avinashjoshi/omacus && cd omacus cargo run --release# open the window cargo test# the engine, pages, time zones, help examples ./install.sh# Linux: build and install for your user

Releases are automatic: bumping version in Cargo.toml on main runs the tests on Linux, macOS and Windows, builds every package, and publishes a GitHub release with notes. Omacus is MIT licensed.
