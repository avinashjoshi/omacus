Get Omacus.

Free and MIT licensed. The latest release, for every platform. Once installed, Omacus tells you when there's a new version and updates in a click.

On a phone or tablet? The downloads below are for computers. Omacus runs in your browser instead, and works offline once you add it to your Home Screen.

Open the web appRuns in your browser. Nothing to install. or download the app

Omarchy & Arch

Installs the app, then offers a keybind (Super Ctrl Alt = by default, checked against yours) and a floating window.

$curl -fsSL https://omacus.com/install | bash

Colors follow your Omarchy theme automatically.

macOS Apple Silicon & Intel

The one-liner picks the build for your Mac's chip, installs Omacus.app into Applications and opens without a security prompt.

$curl -fsSL https://omacus.com/install | bash

Or with Homebrew:

$brew install --cask avinashjoshi/tap/omacus
Apple Silicon .dmg Intel .dmg

Not sure which? Apple menu → About This Mac shows the chip. The app isn't notarized yet. On macOS 15 or later, open it once, then System Settings → Privacy & Security → Open Anyway. On an older Mac, right-click the app and choose Open.

Windows 64-bit

The installer puts Omacus in Start and opens it, with no admin prompt. It updates itself.

Download installer Portable .zip

Or in PowerShell:

PS>irm https://omacus.com/install.ps1 | iex

Omacus isn't signed yet, so a downloaded installer may get a SmartScreen warning: choose More info → Run anyway. The PowerShell line doesn't get one. Uninstall from Settings → Apps; your pages stay.

Other Linux x86_64

The same one-liner works on any distribution, or use a package:

.deb .rpm .tar.gz

Ubuntu: sudo apt install ./omacus-linux-x86_64.deb · Fedora: sudo dnf install ./omacus-linux-x86_64.rpm

Every release

  • What's new lists every version in plain words. GitHub has the files.
  • SHA256SUMS.txt has each file's checksum: sha256sum -c SHA256SUMS.txt --ignore-missing.
  • Runs on 64-bit Linux with glibc 2.35 or newer (Ubuntu 22.04, Fedora 36 and later), macOS 11 or newer, and Windows 10 and 11.
  • Built from source on GitHub for every release. Install notes cover each platform.
