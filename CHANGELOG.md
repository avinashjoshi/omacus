# Changelog

## Unreleased

**Sync paused stays open**

If this computer cannot read the saved copy, sync says so and stays on. The status can be tapped, and it says what it means. Sync stays at the bottom of the sidebar, including while sync is paused. A computer that is still on its own list starts sending again. Join again is there when this computer is not on the list. Nothing already here is deleted.

**The recovery word you tap stays selected**

On the check, the word you tap is the one that stays marked.

**Pages from both phones stay**

A page that is on this phone and missing from the other list stays, and it is sent across. A page is removed only when a delete names that page. Removing more than two pages asks first. Two copies of Welcome to Omacus with the same text become one page.

## 1.0.2

**The phone offers the new version**

An installed copy notices a new version and asks before it reloads. The page you have open is saved first. Pages already on this phone stay on this phone.

**A page on one device stays**

A page that is only on this phone or computer stays, and the other side gets a copy. Deleting a page is what removes it. That page waits in Recently deleted, and Restore puts it back. A copy that would remove most of the pages here removes none.

**Sync is easier to reach**

A phone that asks to join opens the approval on its own. The recovery word you pick stays marked. Sync in the sidebar opens sync again. List changed can be tapped, and it names who joined and who left. That note does not stop a save.

## 1.0.1

**Sync on this computer**

Pages in the desktop app can sync with a phone. Turn on sync stays in this window. The server still cannot read the pages. The sync key stays in the system key store. On a Linux computer with no keyring, you choose a passphrase, and the key stays in a locked file on that computer. Copying the recovery words says that a clipboard history may keep them. Printing them, or writing them down, is safest. Quitting the app clears those words if they are still on the clipboard. Removing a phone or computer stops it from getting new pages. Pages it already saved stay readable on it. When that list changes, this window says so.

**A removed phone keeps its old pages**

Removing a phone or computer stops it from getting new pages. Pages it already saved stay readable on it. When that list changes, Omacus says so. The recovery words can put the list back.

A new invite code lasts 30 days unless a different day is set. Settings shows a build hash, and a public file lists every file in that web build. Copies from before 1.0 check a checksum only. This version checks a signature before it installs an update.

## 1.0.0

**Sync is here**

Sync is here: encrypted sync across your phones and computers, invite-only for now. Your pages are encrypted on your device, and the server cannot read them. [Sync](/sync/) explains how it works, and [Privacy](/privacy/) lists what is sent.
