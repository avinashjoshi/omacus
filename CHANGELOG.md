# Changelog

## Unreleased

**Sync on this computer**

Pages in the desktop app can sync with a phone. Turn on sync stays in this window. The server still cannot read the pages. The sync key stays in the system key store.

## 1.0.0

**Sync is here**

Sync is here: encrypted sync across your phones and computers, invite-only for now. Your pages are encrypted on your device, and the server cannot read them. [Sync](/sync/) explains how it works, and [Privacy](/privacy/) lists what is sent.

## 0.2.20

**The page runs to the edges of the screen**

On iPhone, the sidebar and the page reach the top and the bottom of the screen. The version line and the last line stay above the home indicator. The top bar is a solid colour over the clock. In landscape, the collapsed sidebar buttons take a tap.

## 0.2.19

**The Home Screen app sits on the screen**

On iPhone, the page reaches the bottom edge, and the top bar is a solid colour. A closed pages list no longer leaves a shadow on the page.

## 0.2.18

**The Home Screen app fills the screen**

On iPhone, the top bar is a solid colour, the same as the page. The page and the sidebar reach the bottom edge. A screen reader note no longer shows on the page.

## 0.2.17

**Your pages open again**

The web app was stuck on Loading the engine. Your pages were still in this browser. It opens them again. If it cannot start, it lists the pages and can save a copy.

## 0.2.16

**Two edits of one line stay on the page**

When a page changes here and in another copy, lines that differ are kept together. When both copies changed the same line, Omacus asks you to pick one. A copy of the library is saved before this starts, and the pages stay as they are if that copy cannot be written.

## 0.2.15

**Keep a copy of everything**

Export everything in Settings saves your pages, folders, settings, and Recently deleted in one file. Locked pages are included, and they stay locked.

Exported pages have slimmer margins, so more of the sheet is the note itself. A code block sits with the text, in a monospace face, and a long line wraps instead of running off the page.

On a phone, the top bar matches the page, with no tint in the Home Screen app. Settings opens below the top bar, and the sidebar lists your pages cleanly. The privacy note is in About.

- Settings shows the hash of this web app. The same hash is on the release page, so you can confirm this copy matches the one that was published.
- A locked page is named Locked page in the list, and a reference to it stays locked until you open it.
- On iPhone, Add to Home Screen is offered as soon as the app opens.

## 0.2.14

**PDFs use the page better**

Exported pages have slimmer margins, so more of the sheet is the note itself. A code block sits with the text, in a monospace face, and a long line wraps instead of running off the page.

On a phone, the top bar matches the page, Settings opens below it, and the sidebar lists your pages.

## 0.2.13

**A clearer app on your phone**

The top bar is a solid strip, the sidebar shows the version and Settings, and the page menu only lists what you can do with that page.

- Locking a page asks you to choose a password, then locks it. Save that password in a password manager.
- Removing a lock asks for the password and keeps the page.

## 0.2.12

**The web app works offline**

The web app at app.omacus.com keeps working with no connection after the first visit, and a new version asks before it reloads so an unsaved edit is not lost.

- Opening omacus.com/app brings your saved pages along, then opens the app.
- Opening or switching a page no longer draws a frame around it.

## 0.2.11

**See every update in one place**

The updates page lists each version in plain words, newest first. What's new in the app opens the same page.

## 0.2.10

**A cleaner, calmer look**

The app and the website share one quiet look, in light and dark. Type, spacing, and colour come from the same choices, so a screen matches the site.

- Settings, About, and dialogs use the same frames and buttons
